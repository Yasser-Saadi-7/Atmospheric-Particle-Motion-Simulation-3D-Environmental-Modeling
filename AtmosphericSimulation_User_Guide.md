# Professional User Guide — AtmosphericSimulation

## 1. Project Purpose

The **AtmosphericSimulation** project simulates the three-dimensional motion of atmospheric particles inside a spherical shell surrounding a planet.

The system includes:

- Building and running the C++ code using CMake
- Generating CSV files from simulation results
- Creating plots, heatmaps, 3D visualizations, and animations
- Building a local results website
- Exporting files for reports and ParaView

This guide is intended mainly for the following environment:

- Windows
- WSL Ubuntu
- VS Code or Cursor
- CMake
- Python 3
- A modern web browser

---

## 2. Project Structure

Typical project structure:

```text
AtmosphericSimulation/
├── CMakeLists.txt
├── src/
├── visualization/
├── build/
│   └── output/
├── visualization_output/
├── viz_env/
├── run_full_pipeline.sh
└── README / documentation files
```

### Important Directories

| Directory | Purpose |
|---|---|
| `src/` | C++ simulation source code |
| `build/` | Build files and compiled executable |
| `build/output/` | CSV files generated by the latest simulation run |
| `visualization/` | Scripts for generating plots, animations, and the website |
| `visualization_output/` | Generated website and visualization files |
| `viz_env/` | Python virtual environment |
| `run_full_pipeline.sh` | Automated end-to-end execution script |

## 7. Recommended Full Run

### Standard Command

```bash
cd ~/projects/AtmosphericSimulation
source viz_env/bin/activate

bash run_full_pipeline.sh
```

You may also run:

```bash
./run_full_pipeline.sh
```

### What the Script Does

1. Verifies the project structure.
2. Runs CMake configuration.
3. Builds the C++ project in Release mode.
4. Locates the simulation executable.
5. Deletes old files from `build/output/`.
6. Runs the simulation from the `build/` directory.
7. Verifies that new CSV files were created.
8. Deletes the old website from `visualization_output/`.
9. Runs `visualization/build_dashboard.py`.
10. Regenerates plots, HTML files, images, and animations.
11. Verifies that the main website files were created.

---

## 8. Important Warning About Output Cleanup

During a standard run, the script deletes the previous contents of:

```text
build/output/
visualization_output/
```

This prevents old CSV files from being mixed with new results and prevents outdated generated website files from remaining.

Before an important run, you can create a backup:

```bash
cd ~/projects/AtmosphericSimulation

mkdir -p backups

cp -a build/output \
  backups/output_before_new_run_$(date +%Y%m%d_%H%M%S)

cp -a visualization_output \
  backups/visualization_before_new_run_$(date +%Y%m%d_%H%M%S)
```

## 9. Script Options

### 9.1 Skip Animation Generation

```bash
bash run_full_pipeline.sh --skip-animation
```

Useful for faster testing.

### 9.2 Open the Dashboard After Completion

```bash
bash run_full_pipeline.sh --open-dashboard
```

### 9.3 Change the Number of Visualized Particles

```bash
bash run_full_pipeline.sh --max-particles 8000
```

A higher number may display more particles, but it can increase generation time and memory usage.

### 9.4 Keep Existing CSV Files

```bash
bash run_full_pipeline.sh --keep-simulation-output
```

This is not recommended for a final clean run because old files may be mixed with new results.

### 9.5 Keep the Existing Website Output

```bash
bash run_full_pipeline.sh --keep-visualization-output
```

This is not recommended when outdated generated files may remain.

### 9.6 Combine Options

```bash
bash run_full_pipeline.sh \
  --skip-animation \
  --max-particles 5000
```

### 9.7 Display Help

```bash
bash run_full_pipeline.sh --help
```

## 15. Manual Execution Without the Script

The full pipeline script is the recommended method. Manual execution is useful for troubleshooting.

### 15.1 Build the Project

```bash
cd ~/projects/AtmosphericSimulation

cmake \
  -S . \
  -B build \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_EXPORT_COMPILE_COMMANDS=ON

cmake --build build --parallel "$(nproc)"
```

### 15.2 Locate the Executable

```bash
find build -maxdepth 4 -type f -executable \
  \( -name "AtmosphericSimulation" \
  -o -name "atmospheric_simulation" \)
```

### 15.3 Remove Old Output

```bash
rm -rf build/output
mkdir -p build/output
```

### 15.4 Run the Simulation

```bash
cd build
./AtmosphericSimulation
```

If the executable uses a different name:

```bash
./atmospheric_simulation
```

### 15.5 Generate the Website

```bash
cd ~/projects/AtmosphericSimulation
source viz_env/bin/activate

rm -rf visualization_output
mkdir -p visualization_output

python3 visualization/build_dashboard.py \
  --input build/output \
  --out visualization_output \
  --max-particles 5000 \
  --verbose
```

## 18. Create a Website Package for Another User

Do not send `index.html` by itself.  
Send the entire `visualization_output` directory.

### 18.1 Create a Distribution Directory

```bash
cd ~/projects/AtmosphericSimulation

rm -rf distribution
mkdir -p distribution/AtmosphericSimulation_Visualization

cp -a visualization_output/. \
  distribution/AtmosphericSimulation_Visualization/
```

### 18.2 Create a Windows Startup File

```bash
cat > \
distribution/AtmosphericSimulation_Visualization/START_WEBSITE.bat \
<<'EOF'
@echo off
cd /d "%~dp0"

where py >nul 2>nul
if %errorlevel%==0 (
    start "" http://localhost:8000/
    py -m http.server 8000
    exit /b
)

where python >nul 2>nul
if %errorlevel%==0 (
    start "" http://localhost:8000/
    python -m http.server 8000
    exit /b
)

echo Python was not found.
echo Install Python and run this file again.
pause
EOF
```

### 18.3 Add Instructions for the Recipient

```bash
cat > \
distribution/AtmosphericSimulation_Visualization/README_FIRST.txt \
<<'EOF'
AtmosphericSimulation Visualization Website

1. Extract the entire ZIP archive.
2. Open the extracted folder.
3. Double-click START_WEBSITE.bat.
4. Keep the command window open while using the website.

Do not open index.html directly from inside the ZIP archive.
Do not move index.html away from the assets, html, png, and animations folders.
EOF
```

### 18.4 Create the ZIP Archive

```bash
cd ~/projects/AtmosphericSimulation/distribution

zip -r \
  ../AtmosphericSimulation_Visualization.zip \
  AtmosphericSimulation_Visualization
```

The file to send is:

```text
~/projects/AtmosphericSimulation/AtmosphericSimulation_Visualization.zip
```

### 18.5 Test the ZIP Before Sending

## 20. Troubleshooting

### 20.1 `Permission denied`

```bash
chmod +x run_full_pipeline.sh
```

Then run:

```bash
bash run_full_pipeline.sh
```

---

### 20.2 `cmake: command not found`

```bash
sudo apt update
sudo apt install -y cmake build-essential
```

---

### 20.3 Simulation Executable Not Found

```bash
find build -maxdepth 4 -type f -executable -print
```

Try rebuilding:

```bash
rm -rf build

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel "$(nproc)"
```

Note: deleting `build/` also deletes `build/output/`.

---

### 20.4 No CSV Files Were Created

Search for CSV files:

```bash
find . -type f -name "*.csv" -printf "%TY-%Tm-%Td %TH:%TM %p\n" \
  | sort
```

The correct output location for this project is:

```text
build/output/
```

---

### 20.5 Python Module Error

```bash
source viz_env/bin/activate

pip install --upgrade pip
pip install -r visualization/requirements.txt
```

Or:


## 23. Final Success Checklist

The run is considered successful when:

- CMake configuration completes without errors.
- The C++ build completes successfully.
- The simulation completes without crashing.
- New CSV files exist in `build/output/`.
- `visualization_output/index.html` exists and is not empty.
- `assets/style.css` exists.
- `assets/dashboard.js` exists.
- `assets/generated_manifest.js` exists.
- The website opens with full styling through `localhost`.
- Website plots and links open correctly.
- Old CSV files are not unintentionally mixed with the latest run.
