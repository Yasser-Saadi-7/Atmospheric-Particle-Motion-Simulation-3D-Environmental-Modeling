# Stage UI-2 — Output Collector & Dashboard Manifest

## What Stage UI-2 does

Stage UI-2 connects **existing simulation artifacts** (CSV data, Markdown docs, PNGs,
interactive HTML plots, VTK files, etc.) to the central static visualization dashboard.

It does **not**:
- Run the C++ simulation
- Generate new plots or animations from CSV
- Require any external Python packages

---

```
visualization/

```

---

## How to run

```bash
# From the project root:
python3 visualization/collect_existing_outputs.py
```

Requirements: **Python 3.7+, standard library only.**  
No pip packages needed.

The script:
1. Scans all recognized source directories for visualization artifacts.
2. Copies found files into `visualization_output/` subdirectories.
3. Writes `visualization_output/assets/generated_manifest.js` — a
   JavaScript file that the dashboard reads at load time (no server needed).
4. Prints a summary of what was found, copied, and is still missing.



`visualization_output/` is excluded to prevent self-copies.

## What the manifest contains

`visualization_output/assets/generated_manifest.js` sets `window.DASHBOARD_MANIFEST`:

```javascript
window.DASHBOARD_MANIFEST = {
  "generatedAt":    "2026-06-18T...",
  "availableCount": N,
  "missingCount":   M,
  "isStub":         false,
  "artifacts": {
    "streamfunction": [ { id, title, category, type, filename, relativePath, exists, description }, ... ],
    "meridionalWind": [ ... ],
    "waterBalance":   [ ... ],
    // ... (all 12 categories)
  },
  "expected": [ "streamfunction_heatmap_contours.png", ... ]
};
```

The dashboard reads this at load time and:
- Sets nav-card badges to **AVAILABLE** / **N/A** based on `exists`
- Activates primary link buttons for cards that have available files
- Replaces gallery placeholders with actual images
- Updates the validation section when data CSVs are present

## Scientific wording

All artifact descriptions use cautious language:

- "candidate meridional circulation structure"
- "streamfunction diagnostic"
- "simulation diagnostics"
- "moisture diagnostics"
- "water-balance diagnostics"

The dashboard does **not** claim PASS/WARNING/FAIL unless an actual validation
report is present. Having a data CSV available is shown as "DATA AVAIL." —
not as "PASS".
